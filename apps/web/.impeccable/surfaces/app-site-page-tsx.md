# Surface brief: home page (/) and the app shell

Scope: the public home page at `/` (Persuade) and the app screens under `app/(app)` (Operate), one visual world.
Audience: a small-business owner deciding whether to trust Bursar with Friday's payments; hackathon judges checking the README steps.
Action: "Try it with a sample restaurant" opens `/this-week` in practice mode.
Proof: the six sample invoices, the four real catches, the $900 per-payment limit refusal, the NEAR AI proof check, the sourced fraud figures. No customers, logos or testimonials exist.
Constraints: README "Try it" steps quote on-screen text and must stay true; no gradients (user request); reduced motion respected.

## Direction contract

THESIS: The page is a crossed cheque. Two lines across a cheque mean only the named payee can be paid; Bursar is that crossing made enforceable by the wallet. It refuses the payments-startup default: dark gradient hero, glowing accent, floating app screenshot.

OWN-WORLD: Pale sage security paper, blue-black ink, teal security linework drawn as exact SVG curves (never gradients, glows or blur), red only for void and bounce, ochre only for hold. Archivo: expanded caps for printed field labels, normal width for reading. Martian Mono only for amounts, account numbers and the MICR line. Homemade Apple only for the owner's own hand (payee line, signature). Rubber stamps, perforations, counterfoils, crossings.

STORY: The visitor reads a real cheque to Mama Put Farms Ltd checked four ways, scrolls one week as Bursar drafts cheques for six invoices, voids four with reasons, collects one signature and clears six payments, watches a $5,000 cheque bounce off the $900 limit, then opens the demo.

FIRST VIEWPORT: Ink nav band on top. A two-line headline spans the width. Below it, left: one sentence and one teal CTA "Try it with a sample restaurant"; right: the full cheque with counterfoil stub, the A/C PAYEE ONLY crossing drawing itself, then four ink check marks ticking beside payee, amount, account and invoice number.

FORM: Crossed Cheque, position 1 of my ordered list (taken as IMPECCABLE'S PICK), seed key 5a539f76.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
